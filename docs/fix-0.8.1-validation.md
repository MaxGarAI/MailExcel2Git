# 0.8.1: исправление порога чтения 50 МБ

Причина обращения: вложение около 5 МБ, но запуск отменён с сообщением
«Вложение превышает лимит чтения 50 МБ» после создания backup.

WorkbookReader использовался не только для источников, но и для рабочей копии
общей книги. Порог стоял в нём и в OOXMLPackage. Ошибка из подготовки источника
обычно превращается в отказ отдельного вложения; глобальный отказ с этой формулировкой
приходит из чтения общей книги. Размер небольшого вложения не определяет размер
общей книги, накопившей фотографии других товаров. Порог не являлся ограничением Excel.

## Изменения

- Удалена проверка физического размера 50 МБ из обоих читателей XLSX/XLSM.
- ReadLimits задаёт структурные бюджеты источника и общей книги отдельно.
- Суммарный распакованный объём общей книги не ограничивается бюджетом вложения;
  повышены бюджеты числа частей и XML. Профиль используется для строк, прежних фото
  и проверки сохранённого результата.
- Источник проверяется по ZIP-метаданным до загрузки openpyxl. Проверки OOXML,
  отдельных медиафайлов и корректности данных не отключены.
- Глобальная ошибка и JSON-отчёт называют этап и исходное имя общей книги.
  Backup и атомарная запись сохранены.

## Проверки

211 pytest-тестов успешно; Ruff без ошибок; строгий Mypy — 90 исходных модулей.

Регрессия создаёт настоящий XLSX больше 50 МиБ с 17 встроенными изображениями,
читает строки, все фото и полный снимок общей книги. Другой тест создаёт компактный
архив с 257 МиБ распакованного содержимого: он отклоняется как источник, но читается
профилем общей книги. Отдельный тест проверяет точное имя общей книги в ошибке,
сохранность исходника и наличие backup при отказе чтения.

`tools/verify_large_master.py` успешно выполнен через собранный консольный EXE 0.8.1
в изолированном окружении без путей Python:

| Показатель | Значение |
|---|---:|
| Общая книга до импорта | 53 584 189 байт |
| Вложение | 6 264 байт |
| Общая книга после сохранения | 53 573 364 байт |
| Добавлено товаров | 1 |
| Добавлено нативных фото | 1 |
| Ошибок | 0 |

И до, и после сохранения книга превышает прежние 50 МиБ. Проверка сохранённых
значений и фото прошла. Повтор через тот же EXE не изменил SHA-256 общей книги;
вложение сохранило исходный SHA-256. Рабочие письма и файлы пользователя в тесте
не использовались.

`tools/verify_windows_package.py` проверил хеши 1790 файлов дистрибутива, совпадение
90 исходных модулей, CLI-версию, диагностику и настоящее упакованное окно Tk.
Обновление распространяется полным ZIP 0.8.1. Настройки в LOCALAPPDATA сохраняются.
Приёмка реальной учётной записи Outlook и конкретного Office остаётся на целевом устройстве.
