# 0.8.3: внешнее фото не блокирует импорт данных

## Причина

В присланном MSG одно Excel-вложение с четырьмя товарами. У трёх товаров фото
встроены; у четвёртого blip содержит только r:link на корпоративный сервер,
без встроенных байтов картинки. Это не повреждение остальных данных.
Старый код выдавал PHOTO_READ_FAILED, а при таком же фото в общей книге —
MASTER_PHOTO_INVALID. Отклонялось всё вложение.

## Решение

Корректная внешняя ссылка без встроенного фото отмечается предупреждением
PHOTO_EXTERNAL_LINK. Все товары допускаются к импорту; доступные встроенные фото
переносятся. Прежнее фото сохраняется при отсутствии нового согласно принятой политике.
Если прежнее фото тоже внешняя ссылка, хранится идентичность объекта, а не фиктивный
хеш пикселей. Перед записью заменяемые внешние объекты временно изолируются из OOXML
рабочей копии. После закрытия Excel их drawing-объекты и внешние relationships возвращаются
с новыми координатами, уникальными ID и прежними URL/гиперссылками. Это работает при
смене сезона. Новое встроенное фото заменяет прежнюю внешнюю ссылку.

Встроенный кэш при r:embed имеет приоритет перед r:link. Некорректная relationship,
повреждённые байты и неподдерживаемые зависимости остаются ошибками; рабочая копия
отбрасывается при невозможности сохранить прежний объект. После записи проверяется
наличие каждого сохранённого внешнего объекта. Python-код не загружает внешние URL.
Без байтов картинки внешнее фото нельзя превратить в нативное изображение в ячейке:
прежняя ссылка остаётся привязанным плавающим объектом с предупреждением.

## Проверки

- 229 pytest-тестов; Ruff без ошибок; строгий Mypy — 95 модулей.
- Регрессии: корректная внешняя ссылка, приоритет встроенного кэша, повреждённая
  relationship, чтение старой ссылки в master, предупреждение вместо отказа,
  сохранение URL и координат с существующим drawing и с созданием нового drawing.
- Нативный Excel: обновление товара с сохранением внешнего фото; перенос того же
  объекта на другой сезон; замена внешней ссылки новым встроенным фото.
- Прежние 13 вложений: 90 товаров и 90 фото, 7 коллажей; 82 допущенных товара.
  Только прежние три ошибки неизвестного сезона; 27 исходных файлов без изменений.
- GUI/CLI EXE 0.8.3 запускаются без Python в PATH; проверены хеши 1790 файлов,
  соответствие исходников и запуск tkinter.
