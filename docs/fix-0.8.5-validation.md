# 0.8.5: постоянное исключение ВСЕСЕЗОННОГО

## Причина

Присланное письмо содержит одно Excel-вложение с семью товарами и семью фото.
Шесть товаров — Лето / Лето-осень / Осень, один — ВСЕСЕЗОННЫЙ.
В 0.8.4 последний давал SEASON_UNKNOWN и отклонял всё вложение.
По уточнённому правилу пользователя этот сезон всегда пропускается.

## Реализация

- is_excluded_season распознаёт категорию без учёта регистра/лишних пробелов,
  с наблюдавшимися служебными префиксами, номером и четырёхзначным годом.
  Нечёткое совпадение и произвольные неизвестные сезоны не пропускаются.
- NormalizeWorkbook выделяет IgnoredProduct до проверки поставщика, значений и кэшей
  формул исключённой строки. Связанные фото-строки также исключаются из нормализации.
- BindPhotos не нормализует фото и не использует проблемы, однозначно относящиеся
  к исключённому артикулу. Повреждения обычного товара остаются ошибками.
- PreparedAttachment сохраняет исключённые идентификаторы. В пределах одного запуска
  самое новое исключённое предложение не подменяется старым обычным предложением.
  Противоречие допущенной/исключённой версии с одинаковым временем остаётся ошибкой.
- Пропуск отмечается предупреждением SEASON_EXCLUDED и списком ignored_products
  в предварительном и итоговом отчётах. Итоговый счётчик учитывает пропуски.
- Правило не зависит от добавленных пользователем маршрутов. Существующие данные
  пропущенного товара в общей книге не удаляются. Для обычных ошибок сохраняется
  согласованный атомарный допуск вложения; другие неизвестные сезоны остаются ошибками.

## Проверки

- 267 pytest-тестов успешно; Ruff без ошибок; строгий Mypy — 96 модулей.
- Регрессии: смешанное вложение, неправильные поля/кэш формулы/повреждённое фото
  исключённого товара, полностью исключённое вложение, отсутствующий артикул,
  пользовательский маршрут для исключённого сезона, порядок новых/старых писем,
  конфликт одинакового времени, сохранение атомарности для остальных ошибок.
- Два предупреждения openpyxl при намеренно повреждённом тестовом фото ожидаемы.
  Контрольная сумма этого источника не меняется; библиотека не сохраняет книгу.
- 13 прежних вложений: 89 неисключённых товаров и 89 фото. Значения, маршруты и хеши
  всех этих товаров совпали с прежним сохранённым отчётом. Исключён ровно один товар;
  три Excel-error значения принадлежали только ему и больше не участвуют в импорте.
  Оставшиеся 29 типизированных Excel-error значений сохранены.
- Допускаются 87 товаров вместо прежних 82: восстановлены пять обычных товаров
  смешанного вложения. Две прежние ошибки неизвестного сезона НГ по-прежнему сохраняются.
- GUI/CLI конечной сборки проверены без Python в PATH; хеши 1790 файлов и соответствие
  исходников проверены tools/verify_windows_package.py.

## Присланное письмо через окончательный EXE

Отдельная копия исходной общей книги, отдельный профиль:

| Результат | Количество |
|---|---:|
| Писем / вложений | 1 / 1 |
| Добавлено товаров | 1 |
| Обновлено товаров | 5 |
| Пропущено всесезонных товаров | 1 |
| Добавлено / заменено фото | 1 / 5 |
| Ошибок | 0 |

Сохранённые значения, шесть нативных фото и полный состав прежних артикулов прошли
проверку до commit. Исключённого артикула нет среди записанных товаров.
Повторный EXE-запуск: шесть товаров без изменений, committed=false, SHA-256 книги
не меняется. Исходные MSG, извлечённый XLSX и общая книга сохранили SHA-256.
Рабочие данные, письма, книги, отчёты и журналы не публикуются.
